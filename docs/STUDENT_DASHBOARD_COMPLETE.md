# Student Dashboard V1

This version implements the Week 2–4 student flow from the GitStack plan:

```text
Login → Dashboard → Select Mission → Start Sandbox → Terminal Connected
→ Complete Git workflow → Submit → Bangla feedback → Stored XP/progress
```

Implemented student areas:
- overview dashboard
- mission browser
- mission workspace
- browser terminal
- repository-state validators
- progress + XP
- assessment + Bangla feedback
- team activity summary
- encrypted profile + password management

The collaboration page is database-ready for instructor-created teams and assignments. Gitea Pull Request/review automation remains part of the later collaboration milestone.
