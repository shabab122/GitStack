# Docker and Sandbox Completion Guide

## Completed independent engine

- Docker image with Git, Bash and `script` PTY helper
- Non-root student account
- Temporary workspace
- Resource restrictions
- Isolated and collaboration-ready networking profiles
- Full lifecycle: create, start, inspect, stop, reset and delete
- Approved command API and timeout
- Expiration cleanup
- Standalone smoke tests

## Completed GitStack integration

- JWT authentication and ownership
- PostgreSQL SandboxSession records
- Optional MissionRun linkage
- Browser terminal page
- Authenticated same-origin WebSocket gateway
- Interactive Docker shell stream
- Ctrl+C support
- Start, stop, reconnect, reset and delete controls
- Existing learning pages preserved

## Completion boundary

The sandbox subsystem now creates and manages secure learning workspaces and exposes them through the browser. Mission validation, XP calculation, Bangla assessment feedback, Gitea repository provisioning and Pull Request assessment are separate product features and are not part of the Docker lifecycle subsystem.
