ABOUT THE PROJECT

Git learning that evaluates the complete workflow.

GitStack is a mission-based Git learning and collaboration laboratory where university students first practise safely, then work in controlled teams and receive automatic assessment of both their result and their development process.

PROJECT VISION

More than memorizing Git commands

Students often know commands such as git add, git commit and git push, but struggle to use them correctly inside a real software-development workflow.

GitStack asks four questions

  • What did the student build?
  • How was it built?
  • How did the team collaborate?
  • Was the professional workflow followed?

CORE PRODUCT LAYERS

The complete GitStack learning environment

Learning and missions

Structured lessons and practical missions covering Git basics, branching, remote workflow and collaboration.

Safe Docker sandbox

Each student works inside a separate isolated container with timeout, reset and resource controls.

Gitea collaboration

Real issues, branches, Pull Requests, reviews, approvals and merges inside an instructor-controlled environment.

Workflow assessment

Rule-based validation checks repository state, Git history, Gitea events, tests and merge discipline.

TARGET USERS

Designed for students and instructors

Students

  • Learn through practical missions
  • Use an isolated browser terminal
  • Receive rule-based Bangla feedback
  • Track XP, progress and history
  • Complete role-based team missions

Instructors

  • Assign predefined missions
  • Create three-person teams
  • Monitor individual and team activity
  • Identify common workflow mistakes
  • Review assessment results

COMPLETE TEAM WORKFLOW

From assigned issue to assessed merge

Issue Branch Commit Push Pull Request Review Tests Merge

The MVP uses one deterministic three-person collaboration mission with a prepared merge conflict, separate workspaces and transparent scoring rules.

MVP SCOPE

A focused and realistic first version

The first release concentrates on one complete working flow instead of building a large number of disconnected features.

Included

Authentication, three or four individual missions, browser terminal, Bangla feedback, XP and progress, Gitea team mission, code review, tests, controlled conflict, automatic assessment and basic instructor dashboard.

Future scope

AI chatbot, AI grading, public social network, mobile application, advanced badges, leaderboards, arbitrary mission builder and custom Git hosting are intentionally excluded from the MVP.
